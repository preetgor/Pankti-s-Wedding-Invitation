# Pankti's Wedding Invitation

A ready-to-publish static copy of Pankti's wedding invitation site.
Just `index.html` + the `assets/` folder — no build step, no server needed.

## What's inside

- `index.html` — the whole site: locked cover, Grah Shanti, Sangeet, Wedding Ceremony, Our Families, Social Media page (#panktikishaadi), RSVP with WhatsApp replies, background music, swipe / dot / keyboard navigation
- `assets/` — all artwork (JPEG + lighter WebP copies), the Instagram QR code, and the background music

## Publish with GitHub Pages (free)

1. Create a new **public** repository on GitHub (e.g. `pankti-wedding-invitation`).
2. Upload `index.html`, `README.md`, and the whole `assets` folder into the repo.
3. In the repo: **Settings → Pages → Source: "Deploy from a branch" → Branch: `main` → Folder: `/ (root)` → Save**.
4. Your site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/` in a minute or two.
